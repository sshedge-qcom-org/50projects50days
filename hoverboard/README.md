# Hoverboard

## 1. Project Overview

This project builds a **hoverboard**: a grid of 500 tiny dark squares that light up in a random neon color the instant your mouse touches them, then slowly fade back to dark — leaving a glowing trail everywhere you move.

**Key concepts involved:**

- **Generating DOM elements in a loop** (we don't hand-write 500 squares — JavaScript does).
- Reacting to the **`mouseover`** and **`mouseout`** events.
- Picking a **random** item from an array.
- A clever **CSS transition trick**: instant color *on*, slow fade *off*.

**HTML skills you'll gain:**

- Setting up a minimal page whose content is built entirely by JavaScript.

**CSS skills you'll gain:**

- Building a wrapping grid with Flexbox and `flex-wrap`.
- Using `box-shadow` to create a glow.
- Controlling animation speed with `transition` and overriding `transition-duration` on `:hover`.

**JavaScript skills you'll gain:**

- Creating elements with `document.createElement` and adding them with `appendChild`.
- Building many elements efficiently in a `for` loop.
- Attaching `mouseover` / `mouseout` event listeners.
- Setting inline styles (`element.style.background`, `element.style.boxShadow`) from JavaScript.
- Random selection with `Math.random()` and `Math.floor()`.

---

## 2. Final Project Preview

**Layout & colors:** A near-black page (`#111`). Centered on it is a block (max 400px wide) packed with hundreds of small 16×16 dark-grey squares, arranged in a wrapping grid with tiny gaps between them.

**Behavior & interactions:**

- Moving the mouse across the grid instantly lights each touched square in a random color from a palette of five (red, purple, blue, orange, green), with a matching glow around it.
- As soon as the mouse leaves a square, it **slowly fades** back to dark over about 2 seconds — so your cursor leaves a comet-like trail of fading colors.

**What you can interact with:**

- The entire grid — just hover/move your mouse over it. There are no buttons or inputs.

## 4. Build the Project Step-by-Step

### Step 1: Set Up the HTML Document

**🎯 Goal**
Create the page skeleton with a single empty container that JavaScript will fill with squares.

**💡 Concept**
Unlike most pages, there's almost no HTML here — just one container `<div>`. All 500 squares are generated by JavaScript, which keeps the HTML tiny and the grid size easy to change.

**📝 Code**

```html
<!-- goes in index.html -->
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <link rel="stylesheet" href="style.css" />
    <title>Hoverboard</title>
  </head>
  <body>
    <div class="container" id="container"></div>
    <script src="script.js"></script>
  </body>
</html>
```

**🔍 Explanation**

- `<div class="container" id="container"></div>` — the empty grid holder. The `id` is our JavaScript hook; the `class` is for styling.
- The `<script>` sits at the bottom so the container exists before the script runs.

**✅ Checkpoint**
Open `index.html` — a blank page titled "Hoverboard". Nothing to see yet (the container is empty), and no errors.

### Step 2: Style the Page Background

**🎯 Goal**
Give the page a dark background and center the grid on screen.

**💡 Concept**
Flexbox centering (`align-items` + `justify-content`) puts the grid in the middle. The dark body makes the neon glow pop later.

**📝 Code**

```css
/* goes in style.css */
* {
  box-sizing: border-box;
}

body {
  background-color: #111;
  display: flex;
  align-items: center;
  justify-content: center;
  height: 100vh;
  overflow: hidden;
  margin: 0;
}
```

**🔍 Explanation**

- `* { box-sizing: border-box }` — predictable sizing everywhere.
- `background-color: #111` — the near-black backdrop.
- `display: flex` with both centering properties + `height: 100vh` — centers the grid in the viewport.
- `overflow: hidden; margin: 0` — no scrollbars, no default margin.

**✅ Checkpoint**
The page turns dark. Still empty otherwise — that's expected.

### Step 3: Lay Out the Grid Container

**🎯 Goal**
Make the container a centered, wrapping grid capped at 400px wide.

**💡 Concept**
`flex-wrap: wrap` lets the squares flow onto new rows once they fill a line. Combined with `max-width: 400px`, this decides how many squares fit per row and forms the overall block shape.

**📝 Code**

```css
/* goes in style.css */
.container {
  display: flex;
  align-items: center;
  justify-content: center;
  flex-wrap: wrap;
  max-width: 400px;
}
```

**🔍 Explanation**

- `display: flex; flex-wrap: wrap` — squares sit side by side and wrap to the next row automatically.
- `max-width: 400px` — limits the row width, so the 500 squares form a neat rectangle rather than one long line.
- The centering keeps the block tidy.

**✅ Checkpoint**
No visible change yet — the container is still empty. It's now ready to arrange squares once we add them.

---

### Step 4: Style the Squares

**🎯 Goal**
Define the look of each tiny square and set up the slow fade.

**💡 Concept**
The key here is `transition: 2s ease`. This means any change to a square's properties (like its background or shadow) animates over 2 seconds. That's what will create the slow **fade-back** effect after the mouse leaves.

**📝 Code**

```css
/* goes in style.css */
.square {
  background-color: #1d1d1d;
  box-shadow: 0 0 2px #000;
  height: 16px;
  width: 16px;
  margin: 2px;
  transition: 2s ease;
}
```

**🔍 Explanation**

- `background-color: #1d1d1d` — the resting dark-grey color.
- `box-shadow: 0 0 2px #000` — a subtle default edge.
- `height/width: 16px; margin: 2px` — small squares with tiny gaps between them.
- `transition: 2s ease` — **the fade**: whenever the background or shadow changes, it eases into the new value over 2 seconds.

**✅ Checkpoint**
Still nothing on screen (no squares exist yet). We'll generate them with JavaScript soon — but there's one more CSS trick first.

---

### Step 5: Make the Hover Instant

**🎯 Goal**
Light squares up *immediately* on hover, while keeping the slow fade when the mouse leaves.

**💡 Concept**
This is the heart of the effect. The base square has a 2-second transition. By setting `transition-duration: 0s` **only while hovered**, the color appears instantly on touch — but the moment the mouse leaves, the square is no longer `:hover`, so it reverts to the 2-second transition and fades out slowly.

**📝 Code**

```css
/* goes in style.css */
.square:hover {
  transition-duration: 0s;
}
```

**🔍 Explanation**

- While hovered, `transition-duration: 0s` overrides the base `2s`, so the color change JavaScript applies happens with no delay — instant "on".
- On mouse-out, the `:hover` rule stops applying, the base `2s` transition returns, and the reset-to-dark change fades gently — slow "off".
- Instant-on + slow-off is exactly what makes the glowing trail.

**✅ Checkpoint**
The CSS is complete, but the page is still empty — we haven't created any squares. Time for JavaScript.

---

### Step 6: Set Up the Container, Colors, and Count

**🎯 Goal**
Grab the container and define the color palette and how many squares to make.

**💡 Concept**
We store the possible glow colors in an array and the square count in a constant. Using a named constant like `SQUARES` makes the grid size easy to tweak in one place.

**📝 Code**

```javascript
// goes in script.js
const container = document.getElementById('container')
const colors = ['#e74c3c', '#8e44ad', '#3498db', '#e67e22', '#2ecc71']
const SQUARES = 500
```

**🔍 Explanation**

- `container` — the grid `<div>` we'll fill with squares.
- `colors` — the five-color palette (red, purple, blue, orange, green) we'll pick from at random.
- `SQUARES = 500` — the number of squares to generate. Written in caps by convention to signal it's a fixed configuration value.

**✅ Checkpoint**
No visible change. In the console, type `colors.length` — it should print `5`.

---

### Step 7: Generate the Grid of Squares

**🎯 Goal**
Create 500 squares in a loop, wire up their hover events, and add them to the page.

**💡 Concept**
A `for` loop lets us build many identical elements without repeating code. For each square we create a `<div>`, give it the `.square` class, attach hover listeners, and append it to the container.

**📝 Code**

```javascript
// goes in script.js
for(let i = 0; i < SQUARES; i++) {
    const square = document.createElement('div')
    square.classList.add('square')

    square.addEventListener('mouseover', () => setColor(square))

    square.addEventListener('mouseout', () => removeColor(square))

    container.appendChild(square)
}
```

**🔍 Explanation**

- `for(let i = 0; i < SQUARES; i++)` runs the body 500 times.
- `document.createElement('div')` makes a fresh `<div>`; `classList.add('square')` gives it our styling.
- `mouseover` → call `setColor(square)` to light it up; `mouseout` → call `removeColor(square)` to reset it. We'll write those functions next — that's fine, because JavaScript **hoists** function declarations, so the listeners can reference them before they appear in the file.
- `container.appendChild(square)` adds the finished square to the grid.

**✅ Checkpoint**
Reload the page: the grid of 500 dark squares now fills the centered block. Hovering doesn't do anything visible yet (the color functions aren't written) — next steps fix that.

### Step 8: Pick a Random Color

**🎯 Goal**
Write a helper that returns a random color from the palette.

**💡 Concept**
`Math.random()` gives a decimal from 0 up to (but not including) 1. Multiplying by the array's length and flooring it produces a valid random index into `colors`.

**📝 Code**

```javascript
// goes in script.js
function getRandomColor() {
    return colors[Math.floor(Math.random() * colors.length)]
}
```

**🔍 Explanation**

- `Math.random() * colors.length` → a number from `0` up to `5` (exclusive).
- `Math.floor(...)` rounds it down to a whole number `0`–`4` — a valid index.
- `colors[...]` returns the color at that index. Every call gives a random pick.

**✅ Checkpoint**
No visible change yet. In the console, call `getRandomColor()` a few times — you'll get different hex colors from the palette.

---

### Step 9: Light Up a Square on Hover

**🎯 Goal**
Set a hovered square's color and add a glowing shadow.

**💡 Concept**
We set inline styles directly on the element. The `box-shadow` uses the same color at two blur sizes to create a soft neon glow. Because the square is currently `:hover`ed (so `transition-duration: 0s`), this change appears instantly.

**📝 Code**

```javascript
// goes in script.js
function setColor(element) {
   const color = getRandomColor()
   element.style.background = color
   element.style.boxShadow = `0 0 2px ${color}, 0 0 10px ${color}`
}
```

**🔍 Explanation**

- `const color = getRandomColor()` — pick one random color and reuse it for both the fill and the glow so they match.
- `element.style.background = color` — set the square's background.
- `element.style.boxShadow = '0 0 2px ${color}, 0 0 10px ${color}'` — two stacked shadows (a tight 2px and a wider 10px) in the same color create the glow.

**✅ Checkpoint**
Move your mouse over the grid — squares instantly light up in random neon colors with a glow. They stay lit for now (we haven't written the reset), so the next step completes the effect.

---

### Step 10: Fade the Square Back Out

**🎯 Goal**
Reset a square to its dark resting state when the mouse leaves.

**💡 Concept**
`removeColor` just sets the styles back to the defaults. Because the mouse has left, the square is no longer `:hover`ed, so its base `transition: 2s ease` takes over and the reset **fades** over two seconds — producing the trailing glow.

**📝 Code**

```javascript
// goes in script.js
function removeColor(element) {
   element.style.background = '#1d1d1d'
   element.style.boxShadow = '0 0 2px #000'
}
```

**🔍 Explanation**

- `element.style.background = '#1d1d1d'` — back to the resting dark grey.
- `element.style.boxShadow = '0 0 2px #000'` — back to the subtle default edge (no glow).
- Since these changes happen *after* the mouse leaves, the 2-second base transition animates them, so each square dims gradually instead of snapping off.

**✅ Checkpoint**
Sweep your mouse across the grid: squares light up instantly and then fade back over about 2 seconds, leaving a comet-like trail of color behind your cursor. The hoverboard is complete!

## 6. Recap & Next Steps

**What you learned:**

- Generating many DOM elements efficiently with a `for` loop, `createElement`, and `appendChild`.
- Handling `mouseover` / `mouseout` events and setting inline styles from JavaScript.
- Random selection with `Math.random()` and `Math.floor()`.
- Creating a glow with a two-layer `box-shadow`.
- The instant-on / slow-off trick: a base `transition` combined with `transition-duration: 0s` on `:hover`.
- Why function **hoisting** lets event listeners reference functions defined later in the file.

**Enhancement challenges:**

1. **Responsive count** — calculate `SQUARES` from the viewport size so the grid always fills the screen.
2. **Rainbow mode** — cycle through the palette in order as you move, instead of picking randomly.
3. **Adjustable fade** — add a slider that changes the fade duration by updating the CSS transition.
4. **Click to lock** — make a clicked square keep its color permanently.
5. **Bigger palette** — generate fully random colors with `hsl()` for endless variety instead of a fixed five.
